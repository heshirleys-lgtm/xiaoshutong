# 相伴学 · 学习力 6 维家长报告（Demo）

把「看视频 + 拍书本页 + 语音开放问答 + 做练习」的 APP 学习过程，聚合为面向家长的 **6 维能力画像**，并为每个孩子建立专属成长信息库。

> 在线演示（产品链接）：https://fbe3d0105abd4b59bf98d0d6e6c495c0.app.workbuddy.link

## 产品流程

```
① 看视频 ──记录观看完成度──┐
② 拍书本页 ──OCR 提取页内信息──┼─→ ⑤ AI 聚合分析 ──→ 6 维报告 + 儿童信息库
③ 语音开放问答 ──STT 转写回答──┤
④ 做练习 ──记录正确率────────┘
```

## 6 维分析模型（全部由 AI 分析）

| 维度 | 分析依据 | 输出 |
|------|----------|------|
| 信息提取 | 书本页关键词在回答中的覆盖度 | 0–100 分 + 等级 + 洞察 |
| 推理判断 | 因果/推断类表达信号（因为、推测、由此…） | 同上 |
| 联想迁移 | 生活/经验关联信号（想到、比如、类似…） | 同上 |
| 批判质疑 | 质疑/追问信号（为什么、怀疑、真的吗…） | 同上 |
| 表达组织 | 句数、连接词、平均句长、词汇丰富度 | 同上 |
| 坚持韧性 | 视频完成度 + 练习正确率 + 重试/时长 | 同上 |

综合分 = 六维均值。每维给出家长可读的洞察文案与「给家长的建议」。

## 本地运行

### 1) 后端（可选，仅 web-demo 之外的完整链路需要）

```bash
cd mock-server
node server.js            # 默认 http://localhost:3000
# 预览：浏览器打开 http://localhost:3000/preview.html
```

### 2) 小程序前端（需微信开发者工具）

导入 `mini-learning-app/` → 测试号 AppID → 勾选「不校验合法域名」→ `utils/request.js` 的 `apiBase` 改为后端地址（本机 `http://127.0.0.1:3000`，真机改电脑局域网 IP）。

### 3) 产品链接版（web-demo）

纯静态，直接用浏览器打开 `web-demo/index.html` 即可；也可托管到任意静态服务 / CloudStudio。

## 接入真实 AI（替换 Mock）

所有 Mock 层均预留了真实服务切换点，上层 API 不变：

| 模块 | 切换点 | 建议 |
|------|--------|------|
| OCR | `src/ocr.js` | 腾讯云 OCR / 百度 OCR |
| STT | `src/stt.js` | 微信同声传译 / 讯飞 / Whisper |
| 6 维分析 | `src/analyzer.js` 的 `analyzeLLM()` | OpenAI 兼容大模型，配 `OPENAI_API_KEY` 即用 |
| 信息库持久化 | `src/store.js` | 将 `JsonStore` 换成 SQLite / MySQL 实现同一接口 |

## 技术亮点

- **闭环数据聚合**：把分散在视频、拍照、语音、练习中的多模态学习信号，统一为可量化的 6 维能力。
- **可解释 AI**：每个分数都附带家长视角的洞察与陪伴建议，而非黑盒评分。
- **成长档案**：按儿童 ID 沉淀维度时序，支持成长趋势追踪。
- **平滑演进**：Mock 与真实服务接口一致，可零改动升级到生产级 AI。
